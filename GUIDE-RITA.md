# Guide — Modifier votre site vous-même

*Pour Rita. Aucune connaissance technique nécessaire : si vous savez écrire un e-mail,
vous savez faire tout ce qui suit.*

---

## 1. Se connecter

1. Ouvrez votre navigateur (Chrome de préférence).
2. Allez à l'adresse : **votre-site.fr/admin** (la même adresse que le site, suivie de `/admin`).
3. Cliquez sur **« Sign in with GitHub »** et validez.
   *(La toute première fois, une fenêtre vous demande d'autoriser l'accès : cliquez sur
   « Authorize ». C'est tout, il n'y a pas de mot de passe à retenir en plus.)*

Vous arrivez sur votre tableau de bord : à gauche, la liste de ce que vous pouvez
modifier — **Réglages du site**, **Produits**, **Pages**.

## 2. Modifier un texte (exemple : l'accroche de l'accueil)

1. À gauche, cliquez sur **Pages → Accueil**.
2. Ouvrez le bloc **« Grand bandeau d'entrée »**.
3. Modifiez le champ **« Texte d'accroche »**.
4. En haut à droite, cliquez sur **Enregistrer / Save**.
5. Patientez ~1 minute : le site se met à jour tout seul. Rechargez la page du site
   pour voir le résultat.

> 💡 Dans certains titres vous verrez des petites balises comme `<em>…</em>` (italique)
> ou `<br>` (saut de ligne). Laissez-les en place, modifiez seulement le texte autour.

## 3. Modifier une fiche produit ou en ajouter une

1. À gauche : **Produits → Fiches produits**.
2. Chaque produit est une carte dépliable : cliquez dessus pour modifier son nom,
   sa description, son poids, ses allergènes…
3. **Pour ajouter un produit** (les nouveautés de septembre !) : bouton
   **« Ajouter produit »** en bas de la liste, remplissez tous les champs.
   L'« identifiant technique » s'écrit en minuscules avec des tirets, sans accent
   (exemple : `oeufs-de-saumon`).
4. Enregistrez. La page « La sélection » affichera automatiquement la nouvelle fiche.

> ⚠️ Les **prix** ne sont pas sur le site : ils vivent dans Airtable et s'affichent dans
> le formulaire de commande selon le code partenaire. Pour changer un prix → Airtable.

## 4. Changer une photo

1. Dans le champ photo concerné, cliquez sur l'image puis **« Remplacer / Select »**.
2. Choisissez une image déjà en ligne, ou **envoyez-en une nouvelle** depuis votre
   ordinateur (bouton « Upload »).
3. Enregistrez.

> 💡 Conseil : des photos en format paysage, lumineuses, d'environ 1600 px de large.
> Évitez les fichiers très lourds (plus de 2 Mo) pour garder un site rapide.

## 5. Modifier vos coordonnées (partout d'un coup)

**Réglages du site → Marque & coordonnées** : e-mail, téléphones, adresse.
Un seul endroit à modifier — le pied de page, la page Espace CSE et la page de
commande se mettent à jour partout automatiquement.

Pour les téléphones il y a deux champs : le **numéro affiché** (`07 81 71 51 27`) et le
**numéro pour le lien d'appel** au format international (`+33781715127` — le même numéro
sans le 0 de tête, précédé de +33, sans espaces).

## 6. Les pages légales

**Pages → Mentions légales** (ou **Politique de confidentialité**) : le contenu se
modifie comme un document Word. Les passages sur fond signalé « À compléter » sont à
remplir avant la mise en ligne (SIREN/SIRET notamment).

## 7. En cas de doute

- Vous ne « casserez » rien : chaque enregistrement est conservé dans l'historique,
  tout peut être restauré.
- Le formulaire de commande, les codes partenaires et les prix ne sont **pas** dans ce
  back-office : ils se gèrent dans **Airtable** (voir la documentation Airtable).
